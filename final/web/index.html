Total Star Force

C64 playtest via VirtualC64 Web. Klicka på skärmen eller Start för att köra.

Styrning: ←→↑↓ och Space (joystick port 2). Sidan måste serveras över HTTP (inte file://) så att totalstarforce.prg kan laddas. Autostart använder SYS 2304 (inte RUN). Efter ny build i CBM Prg Studio: kopiera totalstarforce.prg till mappen web/.
