Boss path editor

Klicka i canvas eller skriv X/Y och lägg till waypoint. Välj boss 1/2/3, rita path, kopiera ASM och klistra över BossPath0X/Y, BossPath1X/Y eller BossPath2X/Y i game.asm. Avstånd = form; fart = bossPathSpeed ($20≈10s/varv).

Röd = center. Gul = waypoints. Cyan = loop. Grön zon = där spelaren ofta är (neråt). Streck = max Y från center (±127 signed delta). Full playfield Y 0–240 (player max ≈ 233).
